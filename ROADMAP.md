## Learning modes

### Intensive path
A six-month, high-frequency path emphasizing job readiness, daily coding, production backend systems, and selected AI integration.

### Deep path
A twelve-month or longer path emphasizing broad language and framework mastery, distributed systems, mobile, AI infrastructure, capstones, and open-source work.

## Continuous curriculum threads

The following are not isolated one-time topics. They continue throughout the academy:

- Automated testing in every language and framework
- Git and professional commit practices
- SQL and data modeling
- Security and privacy
- Documentation and architecture diagrams
- Code review and refactoring
- Performance and observability
- Portfolio-quality project delivery
- Interview explanation skills
- Trade-off analysis

## Portfolio strategy

The roadmap follows a backend-first portfolio strategy:

- Production APIs and data systems form the core evidence.
- Frontend and mobile clients demonstrate complete product ownership.
- AI is integrated as a product capability, not used as a substitute for backend engineering.
- Every major phase produces a deployable milestone or case study.
