# Class 002 Assignment

## Question 1

Why should engineers use branches?
    Branches help engineers isolate changes and work on a particular feature or fix at a time without affecting the main branch.


## Question 2

What makes a good commit message?
    A good commit message should be able to describe in a concise and precise manner the changes made.


## Question 3

Explain:

feat: This indicates that the commit is a new feature in the project

fix: This indicates that a bug was fixed with this commit

docs: This indicates that this commit was used to add documentations

refactor: This indicates that the engineer improved already existing code.


## Question 4

What mistakes do beginners make with Git?
    Beginners make so many changes they forget what they changes and have to commit all those changes at once.
