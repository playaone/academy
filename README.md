# Engineering Journey Academy

This directory is the canonical, version-controlled curriculum for the academy.

## Read order for a new session

1. `CURRICULUM_VERSION.md`
2. `COURSE_TRACKER.md`
3. `PROJECT_STATE.md`
4. The next class in `MASTER_SYLLABUS.md`
5. `ROADMAP.md` for long-term context

## Files

### `ROADMAP.md`
The high-level journey, phases, technology tracks, and portfolio strategy.

### `MASTER_SYLLABUS.md`
The permanent numbered class sequence, topics, status, and class deliverables.

### `COURSE_TRACKER.md`
The current position and continuation instructions.

### `PROJECT_STATE.md`
The actual implementation state of the Engineering Portfolio Platform.

### `CURRICULUM_VERSION.md`
The semantic versioning policy and authority rules.

### `CHANGELOG.md`
The dated history of curriculum revisions.

## Core rules

- Never renumber completed classes.
- Never silently overwrite the learner-authoritative class history.
- Do not treat missing chat history as recoverable fact.
- Testing is continuous across every language and framework.
- Every class must update the tracker, project state, changelog, and memory index.
- The repository documents override assistant memory when they disagree.
